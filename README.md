# Govind's personal website

A single-page personal site. It uses plain HTML, CSS, and JavaScript, with no build step.

## Publish with GitHub Pages

1. Create a GitHub repository for this project and push the contents of this folder to its `main` branch.
2. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` deploys the site on each push to `main`. The live URL will appear in the workflow run and the repository's Pages settings.

The site entry point is `index.html`.
